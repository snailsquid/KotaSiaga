KotaSiaga Smart City API v1.1.0

Kondisi kota dan rute aman untuk Bandung Raya: citizen reports and their verification, per-cell risk (Aman / Waspada / Bahaya), weather, official disaster signals, safe routes, area alerts, plus partner data (Tourism destinations, Health donation events) with risk.

Contract status: FINAL (v1.0.0, 2026-11-22). From now on only additive changes; a breaking change needs a new major version and notice to Tourism (JelajahLokal) and Health (DonorKita) first. v1.1.0 (2026-11-28, additive): STB server URL, optional upstream in POST /_mock/scenario, partner examples in JelajahLokal / DonorKita's real formats.

The KotaSiaga mobile app does not call this API directly: it goes through the off-STB Layanan Integrasi at https://kotasiaga.arkk.dev/api (see README.txt), which combines this API with JelajahLokal and DonorKita.

Auth: other groups send their own revocable group key in X-API-Key (ask the KotaSiaga team, see README). App users log in at /auth/login and send Authorization: Bearer <jwt>. Read endpoints and /routes/safe accept either; user actions need the JWT. The gateway rate-limits every client IP (429 rate_limited with Retry-After).

Conventions: JSON, snake_case keys, lowercase enum values, ISO 8601 UTC with Z, meters / seconds / °C, WGS84 lat/lon, bbox = min_lon,min_lat,max_lon,max_lat.

Service area: Bandung Raya (lat -7.10 to -6.75, lon 107.45 to 107.80), split into 500 m cells. A lat/lon outside it returns 422 validation_error; a bbox is clipped to it.

Servers

  • https://2bintang1hati.stei.site/api — KotaSiaga microservice on the STB (K02, Cloudflare tunnel)

Authentication

  • X-API-Key: one revocable key per group (request it from the KotaSiaga team).
  • Bearer JWT: Authorization: Bearer <access_token> from POST /auth/login.

  • auth: POST /auth/register, POST /auth/login, POST /auth/refresh, POST /auth/logout, GET /auth/me

  • partners: GET /monitor-points, GET /destination-points

routes

Safe routes (Rute Aman).

POST/routes/safe

Safe route between two points · auth: X-API-Key or Bearer JWT

Up to 3 candidate routes (OSRM driving alternatives) scored against the current risk grid: cost = duration_s * (1 + 2 * risk_penalty) + 60 s per Waspada cell + 600 s per Bahaya cell. The lowest cost is recommended and listed first. Give destination coordinates or a destination_id from /destination-points. When OSRM is down the last good answer for the same points is reused (meta.stale: true); with none, 503.
